Práctica Integradora de la Asignatura

Proyecto único que articula los cinco temas de Programación Avanzada (GAB-2402): manipulación de datos, visualización, modelado predictivo, bases de datos y aplicación web de analítica.

Objetivo general

Desarrollar un sistema de analítica de datos de extremo a extremo sobre un caso de negocio realista: desde la preparación de datos y su almacenamiento, hasta la exploración visual, el modelado predictivo y la entrega de resultados en una aplicación interactiva, con documentación y presentación final.

Caso de negocio

Una organización con presencia en varias ciudades desea entender el comportamiento de su fuerza laboral y de indicadores asociados (salario, departamento, experiencia, satisfacción, etc.), detectar patrones, estimar variables de interés y disponer de un tablero para consulta por personal directivo o de RR.HH.

Trabajarás con el dataset data/empleados_analitica.csv (incluido en este repositorio). El archivo contiene deliberadamente problemas de calidad de datos (valores faltantes, duplicados, valores atípicos) para que apliques el ciclo completo de preparación.

Temas de la asignatura que se integran

Tema Contenido que se aplica en la práctica
1. Fundamentos de programación avanzada y manipulación de datos Python avanzado, NumPy, Pandas, limpieza, transformación y preparación
2. Visualización avanzada de datos Matplotlib, Seaborn, Plotly; gráficos estáticos e interactivos
3. Análisis estadístico y modelado predictivo Estadística descriptiva e inferencial, ML supervisado, evaluación de modelos
4. Gestión de bases de datos avanzada Diseño de esquema, SQLite/SQL, consultas y persistencia de datos limpios
5. Aplicaciones de analítica y proyecto práctico Aplicación Streamlit (o equivalente), integración de visualizaciones y entrega final

Forma de trabajo

  • Puede realizarse de forma individual o en equipos pequeños (según indicación del docente).
  • Cada entregable se sube al repositorio del equipo (GitHub) en carpetas o ramas claras.
  • El código debe ser reproducible: mismos resultados al ejecutar el notebook o scripts en orden.
  • Se valora la claridad del código, la documentación y la interpretación de resultados (no solo “que corra”).

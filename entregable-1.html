Entregable 1 — Datos listos y persistidos

Temas que cubre: Tema 1 (programación avanzada y manipulación de datos) y Tema 4 (diseño de esquema, carga y consultas básicas en base de datos).

Propósito

Dejar el dataset en condición analítica reproducible y almacenarlo en una base de datos relacional simple (SQLite es suficiente), con documentación del significado de cada variable y de las decisiones de limpieza.

Qué debe incluir este entregable

  1. Exploración inicial del CSV
    • Dimensiones, tipos de datos, muestra de registros.
    • Conteo de nulos, duplicados y valores fuera de rango evidentes.
  2. Pipeline de limpieza y transformación (Python + Pandas/NumPy)
    • Eliminación o tratamiento de duplicados.
    • Imputación justificada de valores faltantes.
    • Tratamiento de valores atípicos (documentar el criterio: IQR, topes, etc.).
    • Normalización de tipos (fechas, categorías, numéricos).
    • Creación de al menos dos variables derivadas útiles para el análisis (por ejemplo rangos de edad, indicadores binarios, ratios).
  3. Diccionario de datos
    • Nombre de variable, tipo, descripción, valores posibles o rango, y notas de calidad.
  4. Diseño y creación de esquema en SQLite
    • Al menos una tabla principal de hechos/empleados limpia.
    • Clave primaria e índices razonables (por ejemplo departamento, ciudad).
    • Opcional: tablas de catálogo (departamentos, ciudades) si normalizas el modelo.
  5. Carga de datos limpios y verificación
    • Inserción desde el DataFrame limpio.
    • Consultas de comprobación (COUNT, agregados por departamento/ciudad).

Productos a entregar

  • Notebook o scripts de limpieza (notebooks/01_limpieza_y_bd.ipynb o equivalente).
  • Archivo SQL del esquema (sql/schema.sql) si aplica.
  • Base SQLite generada o instrucciones inequívocas para regenerarla.
  • Diccionario de datos (Markdown, CSV o sección del notebook).
  • Breve bitácora de decisiones de limpieza (qué se hizo y por qué).
Criterio de “listo” Quien clone el repo y ejecute el notebook en orden debe obtener la misma base limpia y poder consultar agregados básicos sin errores de integridad evidentes.
